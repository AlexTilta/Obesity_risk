# Проект: Мультиклассовое прогнозирование риска ожирения
## [Multi-Class Prediction of Obesity Risk](https://www.kaggle.com/competitions/playground-series-s4e2/data)

# Отчёт о проделанной работе по дисциплине "Бизнес-применение МО"

В рамках задания была проведена подготовка ML-проекта (предсказание уровня ожирения) к production-стандартам.

## 1. Управление зависимостями и окружением (Poetry)
- Инициализирован менеджер пакетов Poetry.
- Созданы файлы `pyproject.toml` и `poetry.lock` для строгой фиксации версий всех библиотек (pandas, scikit-learn, catboost, optuna и др.). Это гарантирует воспроизводимость результатов на любом компьютере.
- Виртуальное окружение изолировано от системного Python.

## 2. Интеграция виртуального окружения в Git
- Добавлен файл `.gitignore`, в который включена папка виртуального окружения (`.venv`, `venv`), а также временные файлы и кэш Python.
- Файлы зависимостей (`pyproject.toml`, `poetry.lock`) закоммичены, чтобы любой разработчик мог развернуть среду одной командой `poetry install`.

## 3. Автоматизация проверки кода (Pre-commit и линтеры)
- Настроен хук `pre-commit` с использованием форматтера `black` и линтера `flake8`.
- Теперь при каждой попытке сделать коммит код автоматически проверяется на синтаксические ошибки и приводится к единому стандарту PEP8.
- Все ошибки линтеров успешно устранены, проверки проходят со статусом Passed.

## 4. Рефакторинг кода под production-стандарты
- Для production-уровня вынесен отдельный скрипт `main.py`, который использует модули из корня проекта (`data_loader.py`, `models.py`, `tuning.py`, `predictor.py`).
- В нем применены лучшие практики:
  - Использование `sklearn.pipeline.Pipeline` (в `tuning.py`), что предотвращает утечку данных при предобработке.
  - Жесткая фиксация `random_state=42` во всех моделях и разбиениях для полной воспроизводимости.
  - Удален "мертвый" код, закомментированные участки и лишние выводы.

## Как развернуть проект
1. Клонировать репозиторий.
2. Установить зависимости: `poetry install --no-root`.
3. Активировать окружение: `poetry shell` (или использовать `poetry run`).
4. Запустить production-скрипт: `poetry run python main.py`.


### Описание проекта
Данный проект направлен на разработку модели машинного обучения для прогнозирования различных уровней риска ожирения у пациентов. Модель будет классифицировать пациентов по нескольким категориям на основе антропометрических, поведенческих и диетологических данных, помогая врачам принимать более обоснованные клинические решения.

Наш проект поможет **выявлять риски ожирения на ранней стадии** и **улучшать профилактику** за счет своевременных медицинских вмешательств.

### Цель проекта
Разработать точную модель мультиклассовой классификации уровня риска ожирения.

### Задачи проекта
1. Провести обработку данных и EDA.
2. Выполнить feature engineering.
3. Обучить несколько моделей и сравнить результаты их обучения.
4. Представить отчет о проделанной работе.
