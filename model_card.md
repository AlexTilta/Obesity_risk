## Информация о модели

### Описание
Obesity Risk Classifier (ORC) — это прогностическая модель машинного обучения, предназначенная для многоклассовой классификации уровня риска ожирения у пациентов. Модель помогает врачам и диетологам выявлять группы риска на ранней стадии на основе комплексного анализа антропометрических данных, пищевых привычек и образа жизни. Модель поддерживает два режима работы: с использованием индекса массы тела (BMI) и без него (только на основе поведенческих факторов).

### Зависимости модели
Модель построена на базе ансамблевого метода **Random Forest** (случайный лес) и интегрирована в пайплайн обработки данных с использованием **Scikit-learn**. Для подбора гиперпараметров использовалась библиотека **Optuna**. Интерпретация результатов обеспечивается встроенными методами оценки важности признаков Random Forest.

### Входные данные
Модель принимает на вход следующие категориальные и числовые признаки:
*   **Антропометрические данные:** `Gender` (Пол), `Age` (Возраст), `Height` (Рост), `Weight` (Вес) — *опционально, в зависимости от режима*.
*   **Пищевые привычки:** `FAVC` (Частое употребление высококалорийной пищи), `FCVC` (Частота употребления овощей), `NCP` (Количество приемов пищи), `CAEC` (Перекусы), `CH2O` (Потребление воды), `CALC` (Употребление алкоголя).
*   **Физическое состояние:** `SCC` (Самоконтроль калорий), `FAF` (Физ. активность), `TUE` (Время за гаджетами), `MTRANS` (Транспорт).
*   **Дополнительные:** `family_history_with_overweight` (Наследственность), `SMOKE` (Курение).

### Выходные данные
*   **Класс риска**: `Insufficient_Weight`, `Normal_Weight`, `Overweight`, `Obesity`.
*   **Вероятность уверенности**: Максимальная вероятность предсказанного класса (от 0.0 до 1.0) для каждого из классов.
*   **Интерпретация**: Ранжирование признаков по их вкладу в решение (Feature Importance).

### Архитектура
Модель представляет собой `Scikit-learn Pipeline`, состоящий из двух шагов:
1.  **StandardScaler**: для масштабирования числовых признаков.
2.  **RandomForestClassifier**: многоклассовый классификатор с оптимизацией гиперпараметров (n_estimators, max_depth, min_samples_split и др.), подобранных через Optuna.

## Данные модели

### Обучающий набор данных
Модель обучалась на датасете **Multi-Class Prediction of Obesity Risk** (Kaggle), который состоит из ~2100 записей и включает данные о людях из Мексики, Перу и Колумбии в возрасте от 14 до 61 года.

### Обработка обучающих данных
*   **Кодирование признаков**: Категориальные признаки преобразованы в числовые с помощью словарей маппинга и `LabelEncoder`.
*   **Разделение**: Стратифицированное разделение на train/test (75/25) для сохранения пропорций классов.
*   **Фиксация**: Все случайные процессы зафиксированы (`random_state=42`) для полной воспроизводимости.

## Оценка

### Методология
Оценка модели проводилась по следующей методологии:
*   **Кросс-валидация**: 5-fold Stratified CV для сохранения пропорций классов.
*   **Out-of-Fold (OOF) оценка**: Оценка вероятностей и метрик на честных предсказаниях.
*   **Метрики**: F1-weighted (главная метрика), Accuracy, ROC-AUC, LogLoss.
*   **Тест на дрейф**: Сравнение распределений train и test выборок.

## Предполагаемое использование и ограничения

### Преимущества и предполагаемое использование
ORC идеально подходит для медицинских учреждений, которым требуется:
*   Раннее выявление пациентов с высоким риском ожирения.
*   Автоматизация рутинной классификации для разгрузки врачей при массовых обследованиях.
*   Создание профилактических программ на основе выявленных рисков.

### Известные ограничения
У модели есть ряд ограничений, которые необходимо учитывать:
*   **Синтетические данные**: Часть обучающей выборки (по данным оригинальной статьи) была синтетически сгенерирована, что может не полностью отражать реальное клиническое разнообразие.
*   **Ограниченный набор признаков**: Без использования BMI, роста и веса модель показывает точность ~82%, что ниже, чем при использовании антропометрии (~98%). Это означает, что в сложных клинических случаях модель может уступать врачу.
*   **Калибровка порога**: Вероятности модели не откалиброваны для использования в качестве абсолютных рисков (требуется дополнительная калибровка).

## Допустимое использование

Модель предназначена исключительно для **поддержки принятия клинических решений (Clinical Decision Support)**. Она не должна использоваться как единственный источник истины для постановки окончательного диагноза без участия квалифицированного медицинского персонала. Запрещено использование модели для автоматического отказа в медицинской помощи или страховке.

---

### Клиническая валидация и экспертная проверка
*   **A/B-тестирование**: Перед полномасштабным внедрением проводится пилотный проект с параллельным принятием решений врачом и моделью.
*   **Ручная проверка "серой зоны"**: Случаи с низкой уверенностью модели (например, < 0.60) передаются на ручную проверку врачом.

## Риски и меры по их снижению

### Риски
*   **Дрейф данных (Data Drift)**: Изменение распределения входных признаков в реальной больнице по сравнению с обучающей выборкой.
*   **Ложное чувство безопасности**: Врачи могут слепо доверять модели, игнорируя клиническую картину.
*   **Смещение (Bias)**: Датасет ограничен странами Латинской Америки, что может снизить точность для других популяций.

### Меры по снижению
*   **Мониторинг**: Настроен еженедельный тест на дрейф данных. При обнаружении дрейфа система генерирует алерт для переобучения.
*   **Порог уверенности**: Случаи с низкой вероятностью передаются на ручную проверку врачом.
*   **План дообучения**: Запланировано переобучение модели раз в 6 месяцев или при накоплении 1000+ новых размеченных случаев из "серой зоны".
*   **Расширение признаков**: В будущих итерациях планируется добавление генетических маркеров и данных о физической активности с носимых устройств.
